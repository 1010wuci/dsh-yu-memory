# dsh-yu-memory

玉的记忆库，做成插件。包内自带五条链，脚本跟着包走，不指向任何 D 盘路径。

## 现在能做的

- 工具 `recall_memory`：给一句平时说的话，从库里挑最相关的几片，带簇、分数、原文摘录和「我当时怎么想」。
- 命令行五条链（都在 `lib/`，库根一律 `--root` 或 `XY_MEMORY_ROOT`）：

  | 干什么 | 脚本 | 有没有第三方依赖 |
  |---|---|---|
  | 召回 | `召回.mjs` | 语义可选（见下） |
  | 写片 | `写片.mjs` | 要调模型（走 DSH 自己的模型接口） |
  | 算主簇 | `分主簇.mjs` | 纯 JS |
  | 重建索引 | `重建索引.mjs` | 纯 JS |
  | 算星图 | `算星图.mjs` | 纯 JS |

- 库根只认参数、配置或环境变量，都没有就报错——不替人猜。

## 语义向量是可选件

召回默认两条腿：字面（词重叠）+ 语义（向量相似）。语义这条缺了不会崩，会照实说明并退回字面 + 簇：

- 没有 `_向量.json`（新库、没算过）→ 结果里 `无语义: true`，`够级` 照给，不谎称「翻不到」。
- 有向量文件但编码跑不起来（没装 transformers、没装 python、解释器路径不对）→ 同样退回字面 + 簇，`语义为何` 里写明原因（实测过：`spawnSync C:\不存在的解释器\python.exe ENOENT`，退出码 0，照样出片）。

两条路按顺序试：先 `@huggingface/transformers`（要自己装到 node_modules），不行再用 python（`XY_PY` 或本机默认路径）+ `lib/算向量.py`。

## 装法

1. 把整个目录放进 DSH profile 的 `node_modules`（或用 `file:` 依赖），
2. profile 的 `package.json` 里加进 `dsh.profile.bundles`，
3. 在 `cordis.patch.yml` 里把 `库根` 改成自己的记忆库目录。

## 配置

| 键 | 说明 | 默认 |
|---|---|---|
| `库根` | 记忆库目录 | 读不到就用环境变量 `XY_MEMORY_ROOT`，都没有就报错 |
| `脚本` | 召回脚本 | 包内 `lib/召回.mjs` |
| `超时毫秒` | 单次召回最长等待 | 30000 |
| `Python` | 语义向量用的解释器（可选） | 读 `XY_PY`；没有就走字面 + 簇 |

环境变量（命令行与插件通用）：

| 变量 | 用途 |
|---|---|
| `XY_ROOT` / `XY_MEMORY_ROOT` | 库根（`--root` 优先） |
| `XY_PY` | 语义向量的 python 解释器 |
| `XY_模型` | 本地 bge 模型目录（`算向量.py` 也不再写死路径） |
| `XY_BAIMINGDAN` | 初筛白名单 json（可选件，没设就当没有） |
| `XY_DEBUG=1` | 打一行库根提示到 stderr（`--json` 时才不污染输出） |

## 可移植性做过什么（2026-11-25）

把包放在一个含空格和中文的路径、库另拷一份、包里没有 `node_modules`（也就没有 transformers）、python 不给——五条链都跑过：

| 场景 | 结果 |
|---|---|
| 不给库根 | `[yu-memory] 没有库根：…`，退出码 2 |
| 库根写错 | `[yu-memory] 库根不存在：D:\不存在的库`，退出码 2（不再抛 fs 栈） |
| 库根对、没向量 | 照常出片，`无语义 true` |
| 分主簇 / 重建索引 / 算星图 | 246 片跑通；索引默认不写盘，加 `--写` 才落 |
| 有向量但解释器不存在 | 退出码 0，照常出片，`语义为何` 写明 ENOENT |

包内已无本机死路径（`初筛规则.mjs` 里那条正则是在识别正文里的路径，故意留的）。
自测脚本 `_验.mjs` 带死路径，已移出包。

## 库的结构（现在硬性依赖）

```
<库根>\
  索引.md             每行：- 编号｜话题｜关键词｜档位｜路径｜簇
  碎片\               一片一个 .md：# 0001｜话题 / 元行 / ## 事实 / ## 我当时怎么想
  _主簇.json          派生（分主簇.mjs 算）
  _向量.json          派生（算向量.mjs + 算向量.py 算，没有 python 就没有它）
  召回基准.json       题集，包内自带一份
```

## 还没做

- 写片还没接成每轮自动的那条路（现在只作命令行，跑一次写一片）。
- 体检、主人裁定、后台这几块是平台侧的，不在这个包里。
- 语义向量的 python 依赖还没去掉，现在只是「缺了能降级、降级会说」。
- 异机实测还没做：本机（装了 transformers）跑通，不等于别人机器跑通。
